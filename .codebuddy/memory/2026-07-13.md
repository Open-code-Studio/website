## 网站重构 — NOTHING UI 设计规范迁移

基于 [NOTHING-UI-1](https://github.com/Open-code-Studio/NOTHING-UI-1) DESIGN_SPEC.md 完整重构 Open Code Studio 网站。

### 关键变更

- **配色**: 绿色调 → 灰度调色板 + Cyan `#00BCD4` 强调色
  - Surface 6层: `#0A0A0A` → `#252525`
  - Text 3级: `#FFF` / `#A0A0A0` / `#6B6B6B`
- **圆角**: 8/14/20/100px → 统一 2px (工业感)
- **装饰**: 移除所有 `.orb` 光晕、`.grid-bg` 网格、`body::before` 噪声纹理
- **导航**: 移除 glassmorphism (`backdrop-filter: blur`)、高度从 64px → 48px
- **动效**: 从 0.3-0.8s 弹性动画 → ≤200ms 快速过渡
- **按钮**: 100px 胶囊 → 2px 直角，32px 高度
- **字体**: 引入 Inter / JetBrains Mono 字体栈
- **间距**: 4px 基础网格系统
- **阴影**: 柔和模糊阴影 → 多层硬阴影
